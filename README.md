# Inside

Симулятор корпоративной IT-среды для стажёров и джунов. Пользователь — Junior Backend Developer в вымышленной компании TechCore: получает задачи, переписывается с виртуальными коллегами, принимает решения и видит последствия и разбор. В конце — отчёт о навыках.

MVP v0 — статический сайт: прогресс хранится в localStorage браузера, сервер не нужен.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # движок, валидатор и все сценарии
npm run lint
npm run build      # статический экспорт в out/
npm run preview    # раздать out/ локально
```

Для деплоя достаточно залить `out/` на любой статический хостинг (GitHub Pages, Vercel, Netlify).

## Тестирование с пользователями

1. Участник проходит онбординг, задачи и анкету в отчёте.
2. Модератор нажимает «Скачать результаты (JSON)», затем «Сбросить прогресс» для следующего участника.
3. Все выгрузки складываем в одну папку и считаем сводку:

```bash
npm run results -- ./results
```

Сводка: доходимость сценариев, уверенность до и после, реалистичность, NPS, клики по fake-door «Inside Pro», комментарии. Полный протокол теста — в [docs/roadmap.md](docs/roadmap.md).

## Структура

```
src/
  app/                    маршруты: лендинг, onboarding, (app)/workspace, scenario/[id], wiki, report
  components/             UI: ScenarioPlayer, TaskBoard, ReportView, SurveyForm…
  content/
    scenarios/*.json      сценарии
    characters.json       коллеги в TechCore
    wiki.json             статьи Wiki
  lib/
    scenario/             типы, движок (replay по выбранным ответам), валидатор графа
    report.ts             навыки, сильные стороны, зоны роста
    export.ts             выгрузка сессии в JSON
    storage/              ProgressRepository и реализация на localStorage
    store/                стор приложения и хук useAppState
scripts/aggregate-results.mjs   сводка по выгрузкам
docs/                     CJM, исследование, отчёт, план
```

Прогресс хранится как список выбранных ответов, а переписка каждый раз заново выводится из контента функцией `replay`. Поэтому правка текстов не ломает сохранённый прогресс. Если выбор пропал из сценария, такой прогресс пропускается, а не считается неверно.

## Как добавить сценарий

1. Создать `src/content/scenarios/<id>.json` и зарегистрировать его в `src/lib/content.ts`.
2. Узлы графа:
   - `message` — реплика коллеги (`from`: id из `characters.json`) или повествование (`from: "system"`), поле `next`;
   - `choice` — вопрос и 2+ варианта: `text`, `next`, `tone` (`good` | `mixed` | `risky`), `feedback` (разбор), `effects` (изменения навыков от −3 до +3), `kind: "action"` для действий вместо сообщений;
   - `end` — концовка с `summary`.
3. `npm test` проверит: все ссылки существуют, нет циклов и недостижимых узлов, каждый путь доходит до концовки, в каждом выборе есть хороший и не-хороший вариант, заявленные навыки действительно тренируются. Битый сценарий не пройдёт и сборку.
